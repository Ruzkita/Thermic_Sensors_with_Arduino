# Thermic_Sensors_with_Arduino

The MiniDAQ is a data acquisition system designed to collect and process information from a wide range of sensors and instruments, primarily used in the testing and monitoring of newly developed devices. As expected, these early-stage devices are not yet optimized and tend to be highly power-consuming, which often leads to overheating of the main system. To address this issue, I developed and prototyped a system aimed at automated temperature monitoring. Beyond just monitoring, this system functions as a safety mechanism by controlling a cooling system that actively cools down the main system when necessary. Additionally, it can shut down the MiniDAQ itself to prevent damage in case of critical overheating. The system was developed using 16 NTC (Negative Temperature Coefficient) sensors, strategically placed at known heat accumulation points. By constantly monitoring these hotspots, the system can take proactive measures to protect the equipment and ensure reliable operation.
